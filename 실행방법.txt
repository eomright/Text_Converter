한국어 받아쓰기 (Korean STT) - 실행 방법
==========================================

내 PC에서 한국어 음성을 텍스트로 바꿔주는 프로그램입니다.
인터넷으로 음성을 보내지 않고, 비용도 들지 않습니다.

  Windows : setup.bat     -> start.bat
  Mac     : setup.command -> start.command   (Mac은 아래 "Mac에서 쓰기" 참고)


[처음 한 번만] 설치  (Windows)
------------------------------------------
1. 이 폴더 안의 setup.bat 을 더블클릭합니다.

2. 파란 "Windows의 PC 보호" 창이 뜨면
   "추가 정보" -> "실행" 을 누릅니다.

3. 검은 창에서 설치가 진행됩니다. (5~10분, 인터넷 필요)
   - Python, ffmpeg 가 없으면 자동으로 설치합니다
   - 음성 모델(약 1GB)을 내려받습니다
   - 중간에 멈춘 것처럼 보여도 기다려 주세요

4. "Setup complete" 가 나오면 아무 키나 눌러 창을 닫습니다.

※ 도중에 [ERROR] 가 나오면 메시지를 확인하고 setup.bat 을 한 번 더 실행하세요.
  이미 끝난 단계는 건너뜁니다.


[매번] 실행  (Windows)
------------------------------------------
1. start.bat 을 더블클릭합니다.

2. 몇 초 뒤 브라우저가 자동으로 열립니다.
   안 열리면 주소창에 직접 입력: http://127.0.0.1:8000

3. 오른쪽 위 배지가 "준비됨" 으로 바뀌면 사용할 수 있습니다. (20~40초)

4. 다 쓰고 나면 검은 서버 창에서 Ctrl + C 를 누르거나 창을 닫습니다.
   ※ 쓰는 동안에는 검은 창을 닫지 마세요.


Mac에서 쓰기
------------------------------------------
[처음 한 번만] 설치
1. 압축을 풀고 setup.command 를 더블클릭합니다.

2. "확인되지 않은 개발자" / "열 수 없습니다" 경고가 뜨면:
   - setup.command 를 우클릭(또는 control+클릭) -> "열기" -> "열기"
   - 그래도 안 되면: 시스템 설정 -> 개인정보 보호 및 보안 -> 아래쪽 "그래도 열기"

3. 터미널 창에서 설치가 진행됩니다. (5~15분, 인터넷 필요)
   - Homebrew, Python, ffmpeg 가 없으면 자동으로 설치합니다
   - Homebrew 설치 중 Mac 로그인 비밀번호를 물어봅니다
     (입력해도 화면에 안 보이는 게 정상입니다. 치고 Enter)
   - 음성 모델(약 1GB)을 내려받습니다

4. "Setup complete" 가 나오면 Enter 를 눌러 닫습니다.

[매번] 실행
1. start.command 를 더블클릭 -> 몇 초 뒤 브라우저가 열립니다.
   안 열리면 주소창에 직접 입력: http://127.0.0.1:8000
2. 다 쓰면 터미널 창에서 control + C 를 누르거나 창을 닫습니다.

※ 더블클릭으로 아무 반응이 없거나 "권한이 없습니다" 가 나오면
  터미널(응용 프로그램 -> 유틸리티 -> 터미널)을 열고
  bash 를 치고 한 칸 띄운 뒤, setup.command 파일을 터미널 창에 끌어다 놓고 Enter.
  (start.command 도 같은 방법으로 실행할 수 있습니다)

※ 브라우저에서 마이크를 허용해도 녹음이 안 되면:
  시스템 설정 -> 개인정보 보호 및 보안 -> 마이크 -> 사용하는 브라우저 켜기


사용법 요약
------------------------------------------
- 녹음: 빨간 버튼 클릭 -> 말하기 -> 다시 클릭
- 파일 변환: 오디오 파일(mp3, m4a, wav, mp4 등)을 화면에 끌어다 놓기
- 결과 저장: txt / srt(자막) / md 버튼
- 강의 녹음: 녹음 환경을 "강의실" 로 바꾸기
  (처음 쓸 때 큰 모델 약 3GB를 추가로 내려받습니다)
- 전문용어를 자꾸 틀리면: "설정 · 용어집" 에 용어를 쉼표로 적어두기
  예) 용어: 대규모 언어 모델, 미세 조정, 선호도 최적화

자세한 내용은 README.md 를 참고하세요.


필요 사양
------------------------------------------
- Windows 10 / 11, 또는 macOS (Apple M1 이상 권장, 구형 Intel Mac은 느릴 수 있음)
- 메모리 4GB 이상 (Mac은 8GB 이상 권장)
- 디스크 여유 공간 2GB 이상 (강의실 모드까지 쓰면 5GB)
- 노트북이면 충전기를 꽂고 쓰세요. 배터리일 때보다 약 2배 빠릅니다.


문제가 생기면
------------------------------------------
- 마이크가 안 잡힘
    -> 브라우저 주소창 왼쪽 자물쇠 아이콘 -> 마이크 "허용"
- start.bat 이 "Run setup.bat first" 라고 함
    -> setup.bat 을 먼저 실행하세요
- 브라우저에 아무것도 안 뜸
    -> 검은 서버 창이 켜져 있는지 확인하고, 잠시 뒤 새로고침
- 너무 느림
    -> 충전기 연결, 다른 무거운 프로그램 닫기

설치된 파일 위치: Windows  C:\Users\(사용자이름)\korean-stt-runtime
                  Mac      /Users/(사용자이름)/korean-stt-runtime
완전히 지우려면 이 폴더와 압축 푼 korean-stt 폴더를 삭제하면 됩니다.
